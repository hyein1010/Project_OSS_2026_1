# 오늘 뭐 먹지? 🎲

메뉴 랜덤 뽑기 & 맛집 지도 웹 애플리케이션

## 실행 방법

```bash
# 1. 패키지 설치
pip install -r requirements.txt

# 2. 서버 실행
python app.py

# 3. 브라우저에서 열기
http://127.0.0.1:5000
```
